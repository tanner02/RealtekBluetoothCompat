# RTL8852B USB 0cb8:c559 on Tahoe

This profile is for x86_64 Tahoe 26.7.2, build 25G332, with Bluetooth USB ID
`0cb8:c559`. It uses `rtl8852bu` firmware. Sequoia and other USB IDs are not
included in this profile.

```sh
./scripts/setup-deps.sh
./build.sh --device rtl8852b
```

For a local copy of the target executable, append
`--binary /path/to/bluetoothd`. The generator checks the native CodeDirectory
`ac367bd0eb64f10ec8673143e52372cf21051491` and the original signed pages.

The patch changes `74` to `EB` at x86_64 slice offset `0x216694`. This enters the
native connection-ready handler instead of waiting for an optional update. The
dispatcher and the PHY branch at `0x216551` stay unchanged. Pairing and encryption
continue through the system's SMP path.

`install.command` detects the USB controller, builds this profile and adds the
firmware-loader match if needed. It preserves other device personalities and
rejects a companion built for the other controller before editing EFI. For manual
installation, use the existing README steps with the Tahoe kernel range and the
[0cb8:c559 firmware fragment](../examples/RealtekBluetoothFirmware-0cb8-c559.plist).

The single-byte patch was tested on a RedmiBook Pro 14 2022 with Ryzen 6800H:
keyboard pairing, an encrypted connection, typing, mouse use and reconnection
after switching the mouse off and on passed. The integration into this repository
has host tests; it has not been installed again on that machine. Audio profiles,
sleep/wake and long-term reconnection remain untested.

## 中文

此配置只适用于蓝牙 USB ID 为 `0cb8:c559` 的 RTL8852B，系统为 x86_64 Tahoe
26.7.2 / 25G332，固件为 `rtl8852bu`。手动构建时使用上面的
`./build.sh --device rtl8852b`；如使用目标系统的本地 `bluetoothd` 副本，再加
`--binary /本地路径/bluetoothd`。

补丁只把 x86_64 slice 中 `0x216694` 的 `74` 改为 `EB`，进入系统原生的连接
就绪处理。分发器和 `0x216551` 的 PHY 分支保持原样，后续配对及加密仍走系统
SMP 流程。原来的 `0bda:0852` 配置继续使用原有四处补丁，仍是默认构建配置。

双击 `install.command` 会识别 USB ID，构建对应配置，并在固件加载器中补上
设备匹配；其他设备的匹配项会保留。手动安装需使用 Tahoe 的内核范围，以及
上面链接的 `0cb8:c559` 固件匹配片段。

此前在 RedmiBook Pro 14 2022 / 6800H 上验证了键盘配对、加密连接、输入、鼠标
使用及鼠标关机后的重连。本次上游移植经过主机测试，尚未重新安装到该机器。
耳机、睡眠唤醒和长期重连还没有验证。
